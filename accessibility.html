Accessibility Statement

Chamber of Hope aims to make the directory usable with keyboard navigation, screen readers, browser zoom, mobile devices, clear headings, descriptive links, and printable pages.

Available access tools

  • Skip-free global navigation and a site search.
  • Language Access and Google Translate pathways.
  • Large touch targets and mobile-friendly forms.
  • Print support and a guided Find My Help pathway.
  • Quick Exit keyboard shortcut: Shift + Escape.

Some older directory pages contain very large sections, repeated link patterns, symbols, or third-party content that may not provide a perfect experience with every assistive technology. Improvements will continue as pages are reviewed.

Report an accessibility barrier by using the problem report form and choosing “Other correction,” or email 8chamber8ofhope8@gmail.com. Include the page name, the barrier, the device or assistive technology used, and the information you were trying to reach.
